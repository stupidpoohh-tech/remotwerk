How it works

설치하고, 연결하고,
작은 몸짓을 보냅니다.

복잡한 커플 기능 대신 한 가지 경험에 집중했습니다. 상대의 캐릭터가 내 화면에 살고, 내가 보낸 몸짓은 상대 화면의 캐릭터가 대신 보여줍니다.

01

Remotwerk 설치

Windows PC에 설치하고 마음에 드는 캐릭터를 고릅니다.

02

둘만 연결

초대 코드를 공유해 두 사람을 연결합니다. 서로 다른 캐릭터를 골라도 됩니다.

03

몸짓 하나 보내기

리모컨에서 신호를 누르면 상대 화면의 내 캐릭터가 움직입니다. 읽음이나 답장 압박은 없습니다.

  • ···혼자서도 살아 있음.

Privacy by design

당신의 화면을
보지 않습니다.

Remotwerk는 상대와 작은 몸짓을 주고받기 위해 필요한 정보만 다룹니다. 업무 화면이나 입력 내용을 읽는 기능을 제품에 넣지 않습니다.

작게 존재하고,
작게 연결합니다.

현재 버전은 화면 캡처, 키 입력, 마이크·카메라, 업무 파일을 수집하지 않습니다. 상대에게도 접속 상태나 현재 사용하는 앱 같은 활동 정보를 보여주지 않습니다.

FAQ

설치하기 전에.

두 사람 모두 설치해야 하나요?

현재 Windows 베타에서는 서로의 화면에서 캐릭터를 주고받으려면 두 사람 모두 Remotwerk를 설치하는 방식입니다.

회사 PC에서도 쓸 수 있나요?

Remotwerk 자체는 화면·키 입력·업무 파일을 읽지 않지만, 회사마다 개인 프로그램 설치와 외부 서비스 통신 정책이 다릅니다. 사내 정책에서 허용되는 PC에서 사용해 주세요.

Windows에서 게시자 경고가 보일 수 있나요?

현재 베타는 정식 코드 서명을 준비 중이라 Windows에서 게시자 또는 SmartScreen 관련 안내가 표시될 수 있습니다. 공개 1.0 전 코드 서명 적용을 목표로 하고 있습니다.

상대가 신호를 읽었는지 알 수 있나요?

알 수 없습니다. 일부러 만들지 않았습니다. Remotwerk는 대답을 요구하지 않는 작은 존재감을 목표로 합니다.

캐릭터는 더 추가되나요?

네. 사용자 업로드보다 Remotwerk가 직접 제작·검수한 캐릭터를 늘리는 방향으로 개발하고 있습니다.
