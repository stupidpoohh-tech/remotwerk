# 애니메이션 검사기

캐릭터가 **찢어져 보이지 않는지**를 프레임 단위로 확인하는 도구다.

리그가 조금만 어긋나도 뉴트럴 포즈에서는 멀쩡해 보인다. v0.6.0 에서 실제로 그랬다 —
정지 화면만 보고 "정상"이라고 판단했는데, 움직이면 몸통이 허리에서 잘려 나갔다.
그래서 **모든 동작의 모든 프레임**을 그려서 본다.

## 쓰는 법

```bash
npm i -D playwright-core                     # 브라우저 구동용
pip install pillow numpy scipy               # 픽셀 분석용

node tools/anim-check/render.js              # 프레임 PNG 생성 (frames/)
python3 tools/anim-check/check.py            # 자동 검사 — 문제 프레임을 찍어 준다
python3 tools/anim-check/sheet.py            # 동작별 한 장으로 묶기 (sheets/) — 눈으로 확인
```

크롬 실행 파일 경로는 `CHROME_PATH` 로 바꿀 수 있다.
`CHARS` / `ANIMS` / `FPS` / `OUT` 환경변수로 범위를 좁힐 수 있다.

## 무엇을 잡는가

`check.py` 가 프레임마다 세 가지를 본다.

1. **몸이 분리됐는가** — 실루엣의 연결 성분이 2개 이상이면 조각이 떨어져 나간 것.
2. **몸 안에 구멍이 났는가** — 실루엣 내부의 빈 영역.
3. **관절이 벌어졌는가** — 팔다리에서 몸통까지의 최단 거리(붙어 있으면 0).

각 조각을 단색으로 칠한 렌더(`*_c.png`)를 함께 만들어서, 어느 조각이 어디에 있는지
픽셀 단위로 구분한다.

**자동 검사만 믿지 말 것.** 여기서 통과해도 "삐져나온 얇은 조각"처럼 눈에는 거슬리는데
수치로는 안 잡히는 경우가 있다. `sheet.py` 로 묶은 시트를 반드시 눈으로 본다.
