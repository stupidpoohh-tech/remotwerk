# library-tools — 전국 도서관 목록 + 희망도서 신청 반자동 도우미

두 개의 독립적인 도구입니다. (Remotwerk 앱 본체와는 무관하며, Node.js 18 이상 필요)

| 도구 | 하는 일 |
|---|---|
| `collect-libraries.mjs` | 도서관 정보나루 Open API로 전국 도서관 목록을 수집하고, 각 홈페이지에서 희망도서 신청 링크를 자동 탐색해 **CSV(엑셀) + 검색 가능한 HTML 사이트**로 출력 |
| `request-helper.mjs` | **내가 회원인 도서관만** 대상으로, 브라우저를 띄워 신청 페이지를 열고 폼을 자동으로 채워주는 반자동 도우미. **로그인과 최종 제출은 항상 사람이 합니다** |

> ⚠️ **꼭 읽어 주세요**: 희망도서 신청은 대부분 해당 지자체 거주 회원만 가능하고, 도서관들은
> 출판사·저자 주도의 조직적 신청(영리 목적)을 선정 제외 기준으로 명시하고 있습니다.
> 이 도구는 **본인이 정당한 회원 자격을 가진 도서관에, 한 건씩 사람이 확인하며 신청**하는
> 용도로만 설계되었습니다. 대량 자동 제출 기능은 의도적으로 넣지 않았습니다.

## 1. 전국 도서관 목록 수집 (`collect-libraries.mjs`)

### 준비: 정보나루 API 인증키 발급 (무료)

1. [도서관 정보나루](https://www.data4library.kr) 회원가입
2. [Open API 활용 신청](https://www.data4library.kr/apiUtilization)에서 인증키 발급 (보통 당일 승인)

### 실행

```bash
cd library-tools

# 목록만 수집 (1~2분)
node collect-libraries.mjs --key 발급받은키

# 목록 + 각 홈페이지에서 희망도서 신청 링크 자동 탐색 (1,400여 곳 접속, 20~40분)
node collect-libraries.mjs --key 발급받은키 --find-request-links

# 테스트: 30곳만
node collect-libraries.mjs --key 발급받은키 --limit 30 --find-request-links
```

인증키는 `DATA4LIBRARY_KEY` 환경변수로도 지정할 수 있습니다.

### 결과물 (`output/`)

- **`libraries.csv`** — 엑셀에서 바로 열리는 스프레드시트 (도서관명, 시도, 주소, 전화, 홈페이지, 희망도서 신청 링크, 휴관일, 운영시간)
- **`index.html`** — 브라우저로 열면 되는 검색·지역 필터 가능한 목록 사이트 (파일 하나로 완결, 서버 불필요)
- **`libraries.json`** — 다른 도구에서 쓰기 위한 원본 데이터

희망도서 링크 탐색은 각 도서관 메인 페이지의 메뉴를 읽어 추정하는 방식이라,
로그인 후에만 보이는 메뉴이거나 자바스크립트 메뉴인 경우 못 찾을 수 있습니다
(`링크상태` 열에 사유가 기록됩니다).

### 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--key` | env `DATA4LIBRARY_KEY` | 정보나루 인증키 |
| `--out` | `./output` | 출력 디렉터리 |
| `--find-request-links` | 꺼짐 | 홈페이지별 희망도서 링크 탐색 |
| `--concurrency` | 4 | 링크 탐색 동시 접속 수 (예의상 낮게 유지) |
| `--delay` | 300 | 링크 탐색 요청 간 지연(ms) |
| `--limit` | 전체 | 수집 개수 제한 (테스트용) |

## 2. 희망도서 신청 반자동 도우미 (`request-helper.mjs`)

### 준비

```bash
cd library-tools
npm install
npx playwright install chromium   # 브라우저 1회 설치

cp config.example.json config.json
```

`config.json` 을 열어 채웁니다:

- **`book`** — 신청할 책 정보. `title` 은 필수, `isbn`·`author`·`publisher` 는 채울수록 폼 자동 입력이 정확해집니다. ISBN은 [서지정보유통지원시스템](https://bnk.nl.go.kr) 이나 온라인 서점에서 확인하세요.
- **`libraries`** — **본인이 회원 가입되어 있는** 도서관 목록. `url` 은 홈페이지 주소, `requestUrl` 은 희망도서 신청 페이지 주소(알면 지정, 모르면 빈칸 — 자동 탐색을 시도합니다). 1번 도구의 CSV에서 복사하면 편합니다.

### 실행

```bash
node request-helper.mjs
```

동작 방식 (도서관 한 곳씩 순서대로):

1. 크로미움 브라우저가 뜨고 도서관 페이지가 열립니다. 희망도서 메뉴 링크가 보이면 자동으로 이동합니다.
2. **브라우저에서 직접 로그인**하고 신청 폼 화면까지 이동합니다. (로그인 세션은 `user-data/` 에 저장되어 다음 실행 때 유지됩니다)
3. 터미널에 `f` 를 입력하면 폼의 서명·저자·출판사·ISBN·비고 칸을 자동으로 채웁니다.
4. 제출 후보 버튼은 **빨간 테두리로 강조만** 됩니다. 내용 확인 후 **제출은 직접 클릭**하세요.
5. `n` 으로 다음 도서관으로 넘어가고, `q` 로 종료합니다.

### 팁과 한계

- 도서관마다 폼 구조가 달라 일부 항목은 못 채울 수 있습니다. 못 채운 칸은 직접 입력하세요.
- 신청 전 그 도서관 소장 여부를 먼저 검색하세요 — 이미 소장 중이면 반려됩니다.
- 대부분의 도서관은 1인당 월 3~5권 신청 제한이 있습니다.
- 크로미움 경로를 직접 지정하려면 `config.json` 의 `chromiumPath` 또는 환경변수 `CHROMIUM_PATH` 를 사용하세요.
